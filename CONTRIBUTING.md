# Contributing

## Before opening a pull request

- Không đưa token, `.env`, file upload thật hoặc dữ liệu cá nhân vào repository.
- Không thêm dependency có license xung đột với [LICENSE](LICENSE).
- Cập nhật tài liệu và test nếu thay đổi hành vi.

## Developer Certificate of Origin

Bằng cách gửi contribution, bạn xác nhận rằng bạn có quyền gửi nó và cấp cho chủ dự án quyền phát hành contribution đó theo [PolyForm Noncommercial License 1.0.0](LICENSE).

Thêm dòng sau vào message commit:

```text
Signed-off-by: Your Name <your.email@example.com>
```

Git:

```powershell
git commit -s -m "Mô tả thay đổi"
```

Không ký thay cho người khác.
