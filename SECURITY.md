# Security policy / Chính sách bảo mật

Security policy for File Upload, the self-hosted file manager.

## English

### Reporting a vulnerability

Do not report vulnerabilities in public GitHub issues.

Email [anh.bui@anhbui.dev](mailto:anh.bui@anhbui.dev). If unavailable, email [btanh82@gmail.com](mailto:btanh82@gmail.com). Include the affected version, reproduction steps, impact, and a safe proof of concept. Do not send access tokens or private workspace files.

We will acknowledge valid reports and coordinate a fix before public disclosure where practical.

### Supported versions

Only the current `main` branch receives security fixes while the project is in active development.

## Tiếng Việt

### Báo lỗ hổng

Không báo lỗ hổng qua GitHub issue công khai.

Gửi email tới [anh.bui@anhbui.dev](mailto:anh.bui@anhbui.dev). Nếu không nhận phản hồi, gửi [btanh82@gmail.com](mailto:btanh82@gmail.com). Nêu phiên bản bị ảnh hưởng, cách tái hiện, mức tác động và proof of concept an toàn. Không gửi access token hoặc file riêng tư trong workspace.

Chúng tôi sẽ xác nhận report hợp lệ và phối hợp sửa trước khi công khai khi phù hợp.

### Phiên bản được hỗ trợ

Chỉ nhánh `main` hiện tại nhận security fix trong thời gian dự án đang phát triển.
