# Security policy

## Reporting a vulnerability

Do not report security vulnerabilities in public GitHub issues.

Email [anh.bui@anhbui.dev](mailto:anh.bui@anhbui.dev). If unavailable, email [btanh82@gmail.com](mailto:btanh82@gmail.com). Include affected version, reproduction steps, impact, and a safe proof of concept. Do not send upload tokens or private user files.

We will acknowledge valid reports and coordinate a fix before public disclosure where practical.

## Supported versions

Only the current `main` branch receives security fixes while the project is in active development.
